## 一句话概括

串是字符的线性表，重点是 KMP 模式匹配（O(n+m)）；数组的考点是多维地址计算与对称矩阵压缩存储；广义表的考点是长度 / 深度计算和 head / tail 运算。本章概念题和计算题并重。

## 核心概念

### 串（String）

- 串长 = 字符个数；空串长度 0；空白串由空格组成（非空）
- 存储：定长顺序（char 数组 + '\0'）、堆分配（动态 malloc）、链式

### 数组

**二维数组地址计算**（行优先存储）：

```
LOC(a[i][j]) = LOC(a[0][0]) + (i × n + j) × L
```
其中 n = 列数，L = 每个元素占用字节数。列优先时公式相应调整。

**对称矩阵压缩**：只存下三角（含对角线），一维数组大小 n(n+1)/2。

```
k = i(i+1)/2 + j    （当 i ≥ j，即下三角区域）
```

**稀疏矩阵**：三元组存储 `(行, 列, 值)`，只存非零元素。

### 广义表

- 广义表 LS = (a₁, a₂, ..., aₙ)，其中 aᵢ 可以是**原子**或**子表**
- **长度**：顶层元素个数（逗号数 + 1）
- **深度**：括号嵌套最大层数
- **表头** head(LS)：第一个元素（可以是原子或子表）
- **表尾** tail(LS)：除表头外剩余元素构成的表（**一定是广义表**）

```
head((a,b,c)) = a            # 原子
tail((a,b,c)) = (b,c)        # 广义表
head(((a,b),c)) = (a,b)      # 子表
tail(((a,b),c)) = (c)        # 广义表

# 注意区分：
# ( )    空表，长度 0
# (( ))  长度 1 的表，表头和表尾都是空表 ( )
```

## 关键原理 / 算法

### KMP 模式匹配（高频考点）

朴素匹配：主串指针 i 回溯，最坏 O(n×m)。KMP 利用已匹配信息，i 不回溯，O(n+m)。

**next 数组**：`next[j]` 表示模式串 T[0..j-1] 的最长相等前后缀长度 + 1。

```
next[j] = {
    0,              j = 0（哨兵）
    1,              j = 1
    max{k | 1<k<j 且 T[1..k-1] = T[j-k+1..j-1]} + 1
    1,              其他（无相等前后缀）
}
```

**手动求 next 数组**（常考）：

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| T[j] | a | b | a | a | b | c | a | c |
| next[j] | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |

- j=1: next=0（约定）
- j=2: "a" 无真前后缀，next=1
- j=3: "ab" 最长相等前后缀长 0，next=1
- j=4: "aba" 最长相等前后缀 "a" 长 1，next=2
- j=5: "abaa" 最长相等前后缀 "a" 长 1，next=2
- j=6: "abaab" 最长相等前后缀 "ab" 长 2，next=3
- ...

**KMP 匹配过程**：当 T[j] ≠ S[i] 时，j 回退到 next[j]，i 不动；若 j=0 则 i++, j++。

```python
def kmp(text, pattern):
    n, m = len(text), len(pattern)
    next_arr = [0] * m
    # 求 next 数组
    j, k = 0, -1
    next_arr[0] = -1
    while j < m - 1:
        if k == -1 or pattern[j] == pattern[k]:
            j += 1; k += 1
            next_arr[j] = k
        else:
            k = next_arr[k]
    # 匹配
    i = j = 0
    while i < n and j < m:
        if j == -1 or text[i] == pattern[j]:
            i += 1; j += 1
        else:
            j = next_arr[j]
    return i - j if j == m else -1

print(kmp("ababaababcb", "abababc"))  # 返回匹配位置
```

## 易错点 / 高频考点

- [ ] 广义表 tail 一定是**表**（保留最外层括号），head 可以是原子或子表
- [ ] 空表 `()` 长度 0；`(( ))` 长度 1（表头和表尾都是空表）
- [ ] 对称矩阵压缩下标公式 `k = i(i+1)/2 + j`（i ≥ j），考试常考已知 k 求 i,j
- [ ] next 数组求法：找 pattern[0..j-1] 的最长相等前后缀（**不包括自身**）
- [ ] 二维数组行优先地址计算中 `i × n + j` 的 n 是**列数**，不是行数
- [ ] KMP 中 i 永远不回退，只有 j 回退到 next[j]

## 经典例题

### 例题：广义表 head/tail 运算

**题干**：已知 C = (a,(b,c),d)，求 tail(head(tail(C)))。
**解答**：
1. tail(C) = ((b,c),d)
2. head(tail(C)) = (b,c)
3. tail(head(tail(C))) = tail((b,c)) = (c)

### 例题：对称矩阵地址计算

**题干**：10 阶对称矩阵 A，行优先压缩存于一维数组 B[0..54]，求 A[8][5] 在 B 中的下标。
**解答**：8 ≥ 5，用下三角公式 k = 8×(8+1)/2 + 5 = 36+5 = 41。
