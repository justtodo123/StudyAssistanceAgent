## 一句话概括（TL;DR）

> 拓扑排序在线性序列中表达有向无环图的先后约束，关键路径则在 AOE 网络中找出决定工程最短工期的最长活动路径。

## 核心概念

- AOV 网用顶点表示活动，边表示先后约束；有向环意味着任务依赖矛盾。
- Kahn 算法反复删除入度为 0 的顶点，也可用 DFS 的完成时间生成拓扑序。
- AOE 网用边表示活动，事件顶点表示里程碑，关键活动的总时差为 0。

## 关键原理 / 算法

- 拓扑排序若最终输出顶点数少于图中顶点数，说明图中存在环。
- 关键路径计算先正推事件最早发生时间 ve，再逆推最迟发生时间 vl。
- 活动最早开始 e、最迟开始 l 满足 l-e=0 时属于关键活动，关键路径可能不止一条。

## 易错点 / 高频考点

- [ ] AOV 与 AOE 的顶点、边含义相反，不能直接套用同一套公式。
- [ ] 拓扑序不唯一时，使用最小编号或字典序通常只是为了得到确定输出。

## 经典例题

**题干**：课程项目依赖图中，若 A→C、B→C，只有 A、B 都完成后 C 才能开始；拓扑序可为 A、B、C 或 B、A、C。

**解答**：先明确对象、状态和边界条件，再按条目中的定义逐步推导；计算题应在最后检查单位、符号和复杂度。
