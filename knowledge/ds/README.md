## 重点 / 难点（高频考点速览）

- 时间复杂度推导（递归式 / 常见量级排序）
- 顺序表 vs 链表对比、单链表逆置 / 合并等操作伪码
- 栈与递归关系、循环队列判空判满、表达式求值
- 二叉树性质（n0=n2+1 等）、遍历序列互推、线索二叉树、哈夫曼树构造与 WPL
- 图：邻接矩阵 / 邻接表、DFS/BFS、Prim/Kruskal、Dijkstra/Floyd、拓扑排序、关键路径
- 查找：折半判定树、BST 删除、AVL 四种旋转、B/B+ 树对比、哈希冲突处理与 ASL 计算
- 排序：各算法时间 / 空间 / 稳定性对比、堆排序建堆过程、快排划分、归并趟数计算
