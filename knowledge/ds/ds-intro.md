## 一句话概括

数据结构研究数据元素间的逻辑关系、存储表示及在其上的运算；算法分析以时间复杂度和空间复杂度衡量效率。本章是全书术语与量级的公共基础。

## 核心概念

### 数据结构三层含义

1. **逻辑结构**：集合、线性（一对一）、树形（一对多）、图形（多对多）
2. **存储结构（物理结构）**：顺序存储（地址连续）、链式存储（任意单元 + 指针）
3. **运算**：在结构上定义的操作（插入 / 删除 / 查找 / 修改 / 遍历）

> 教材中「数据结构是相互之间存在一种或多种特定关系的数据元素的集合」。

### 基本术语

- **数据元素**：数据的基本单位（一张表中的一行记录）
- **数据项**：构成数据元素的不可分割最小单位（姓名、性别等字段）
- **数据对象**：性质相同的数据元素的集合（一张表）
- **抽象数据类型（ADT）**：数据对象 + 其上操作集（与实现无关），类似 C 的 struct + 函数、C++/Java 的类

## 关键原理 / 算法

### 算法评价标准

正确性、可读性、健壮性、高效性（时间 + 空间）。

### 时间复杂度推导

- 基本操作（最深层语句）执行次数是问题规模 n 的函数 f(n)，取增长最快的项、去常数 → O 记号
- 常见量级（从优到劣）：
  `O(1) < O(log n) < O(n) < O(n·log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)`

```python
# 示例：二重循环 O(n²)
def sum_matrix(a, n):
    s = 0
    for i in range(n):        # n 次
        for j in range(n):    # 内层 n 次
            s += a[i][j]
    return s                  # 共 n² 次基本操作
```

### 空间复杂度

算法运行所需辅助空间（不计输入本身占用的空间）随 n 增长的量级；递归算法需计入调用栈深度。

## 易错点 / 高频考点

- [ ] 逻辑结构 ≠ 存储结构：同一逻辑结构可用不同存储实现（如线性表可顺序也可链式）
- [ ] 时间复杂度比较：`O(n·log n)` 优于 `O(n²)`；`O(2ⁿ)` 属指数级不可接受
- [ ] 递归算法的空间复杂度要看递归深度，不是看递归次数
- [ ] 循环体执行次数 vs 语句频度：常数项与低次项在 O 记号中省略

## 经典例题

**题干**：求 `i=1; while(i<=n) i=i*2;` 的时间复杂度。
**解答**：循环执行 x 次后 i=2ˣ，由 2ˣ ≤ n 得 x ≤ log₂n，复杂度 O(log n)。
