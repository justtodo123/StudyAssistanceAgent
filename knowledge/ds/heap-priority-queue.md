## 一句话概括

堆是一棵完全二叉树，满足堆序性质（大根堆：父≥子；小根堆：父≤子）。用数组存储，下标关系 `parent=i/2`、`left=2i`、`right=2i+1`。核心操作是上浮（insert）和下沉（delete），均为 O(log n)。堆排序通过反复取堆顶实现 O(n log n) 排序；建堆过程 O(n)。优先队列的底层实现首选堆。

## 核心概念

### 堆的定义与存储

**完全二叉树 + 堆序性质** = 堆

| 类型 | 堆序 | 用途 |
| --- | --- | --- |
| 大根堆 | 父结点 ≥ 子结点 | 取最大值 O(1) |
| 小根堆 | 父结点 ≤ 子结点 | 取最小值 O(1) |

**数组存储**（从下标 1 开始）：
- 结点 `i` 的父结点：`⌊i/2⌋`
- 结点 `i` 的左孩子：`2i`
- 结点 `i` 的右孩子：`2i+1`

```c
typedef struct {
    ElemType *data;  // 从 data[1] 开始存储
    int size;        // 当前元素个数
    int capacity;    // 最大容量
} MaxHeap;
```

### 核心操作

**上浮（Sift Up）**：插入元素后，从叶子向根方向调整。
```
insert(x): 放到末尾 → 与父比较，比父大则交换 → 重复直到满足堆序
时间：O(log n)（最多上升树高）
```

**下沉（Sift Down）**：删除堆顶后，从根向叶子方向调整。
```
deleteTop(): 末尾元素放到堆顶 → 与较大子交换 → 重复直到满足堆序
时间：O(log n)（最多下降树高）
```

```c
// 大根堆的下沉操作
void SiftDown(MaxHeap *H, int i) {
    while (2 * i <= H->size) {
        int child = 2 * i;
        // 选较大的子结点
        if (child < H->size && H->data[child] < H->data[child + 1])
            child++;
        if (H->data[i] >= H->data[child]) break;  // 已满足堆序
        swap(&H->data[i], &H->data[child]);
        i = child;
    }
}
```

### 建堆（Heapify）

**方法**：从最后一个非叶子结点（`⌊n/2⌋`）开始，依次向前做下沉操作。

**时间复杂度**：O(n)（不是 O(n log n)！）
- 证明：高度为 h 的结点约 n/2^(h+1) 个，每个下沉 O(h)
- 总计 = Σ(h=0 到 log n) n·h / 2^(h+1) = O(n)

```c
// 建大根堆
void BuildMaxHeap(MaxHeap *H) {
    for (int i = H->size / 2; i >= 1; i--)
        SiftDown(H, i);
}
```

### 堆排序

**思路**：
1. 建大根堆 O(n)
2. 反复：交换堆顶与末尾 → 堆大小减 1 → 下沉调整堆顶 → O(n log n)

**性质**：
| 指标 | 值 |
| --- | --- |
| 时间（最好/最坏/平均） | O(n log n) |
| 空间 | O(1)（原地排序） |
| 稳定性 | **不稳定** |

```c
void HeapSort(ElemType A[], int n) {
    // 1. 建大根堆
    for (int i = n / 2; i >= 1; i--)
        SiftDown(A, i, n);
    // 2. 取堆顶、调整
    for (int i = n; i > 1; i--) {
        swap(&A[1], &A[i]);     // 堆顶放末尾
        SiftDown(A, 1, i - 1);  // 调整剩余
    }
}
```

### 优先队列

**优先队列**：每次取出优先级最高（值最大或最小）的元素。

| 实现 | 插入 | 取最值 | 删除最值 |
| --- | --- | --- | --- |
| 无序数组 | O(1) | O(n) | O(n) |
| 有序数组 | O(n) | O(1) | O(1) |
| **堆** | **O(log n)** | **O(1)** | **O(log n)** |

堆是优先队列的最佳平衡实现。

## 易错点 / 高频考点

- [ ] 建堆是 O(n) 而非 O(n log n)——从最后一个非叶子结点开始下沉
- [ ] 堆排序**不稳定**：交换堆顶与末尾可能改变相等元素的相对顺序
- [ ] 删除堆顶后用**末尾元素**填补（不是用较大的子结点），再下沉
- [ ] 数组下标从 1 开始时，父/子关系公式才简洁；从 0 开始需偏移
- [ ] 大根堆用于升序排列（每次把最大的放末尾），小根堆用于降序

## 经典例题

### 例题：建堆过程

**题干**：对序列 {4, 1, 3, 2, 16, 9, 10, 14, 8, 7} 建大根堆，写出建堆后数组。

**解答**：
1. 数组（下标 1 起）：`[4, 1, 3, 2, 16, 9, 10, 14, 8, 7]`，n=10
2. 从 `i=5`（⌊10/2⌋）开始下沉：
   - i=5：16 > 8,7，无需调整
   - i=4：2 < 14,8 → 交换 2↔14 → `[4,1,3,14,16,9,10,2,8,7]`
   - i=3：3 < 9,10 → 交换 3↔10 → `[4,1,10,14,16,9,3,2,8,7]`
   - i=2：1 < 14,16 → 交换 1↔16 → `[4,16,10,14,1,9,3,2,8,7]`
   - i=1：4 < 16,10 → 交换 4↔16 → `[16,14,10,14?,4,9,3,2,8,7]` ... 最终：`[16, 14, 10, 8, 7, 9, 3, 2, 4, 1]`
