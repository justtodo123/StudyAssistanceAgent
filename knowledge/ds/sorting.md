## 一句话概括

内部排序将 n 个记录在内存中按关键字排列。考试核心是各算法的**时间 / 空间复杂度与稳定性对比**，以及快排划分、堆排序建堆、归并排序趟数的手工模拟。本章是选择题 + 手工排序题的高频出题区。

## 核心概念

### 排序基本术语

- **稳定性**：若排序前 A₁=A₂ 且 A₁ 在 A₂ 前，排序后仍保持此顺序 → 稳定；否则不稳定
- **内部排序**：记录全在内存；**外部排序**：需访问外存（归并为主）
- 存储：顺序表排序需移动记录；链表排序只需修改指针

### 内部排序全景对比（必背）

| 算法 | 平均 | 最好 | 最坏 | 空间 | 稳定 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| **直接插入** | O(n²) | O(n) | O(n²) | O(1) | ✅ | 基本有序时最优 |
| 折半插入 | O(n²) | O(n²) | O(n²) | O(1) | ✅ | 查找用折半，移动次数不变 |
| **希尔排序** | O(n^(1.3~2)) | — | — | O(1) | ❌ | 缩小增量，跳跃移动 |
| **冒泡排序** | O(n²) | O(n) | O(n²) | O(1) | ✅ | 有序时一趟即可停止 |
| **快速排序** | **O(n·log n)** | O(n·log n) | O(n²) | O(log n)~O(n) | ❌ | 平均最快，最坏退化 |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ✅(实现可不稳定) | 移动次数最少 O(n) |
| **堆排序** | **O(n·log n)** | O(n·log n) | O(n·log n) | O(1) | ❌ | 不受初始状态影响 |
| **归并排序** | **O(n·log n)** | O(n·log n) | O(n·log n) | **O(n)** | ✅ | 稳定 + 最坏保证，空间代价大 |
| 基数排序 | O(d·(n+r)) | — | — | O(n+r) | ✅ | d=位数, r=基数；非比较排序 |

> **三个 O(n·log n)**：快排（平均最快，但最坏 O(n²)）、堆排序（空间最小，稳定 O(n·log n)）、归并排序（稳定，空间 O(n)）。

## 关键原理 / 算法

### 快速排序（高频手工题）

**核心**：选一个枢轴（pivot），将序列划分为「≤ pivot」和「> pivot」两部分，递归处理。

```c
// 严蔚敏教材版：枢轴选第一个元素，先从右往左扫描
int Partition(SqList &L, int low, int high) {
    L.r[0] = L.r[low];                 // 枢轴暂存
    int pivotkey = L.r[low].key;
    while (low < high) {
        while (low < high && L.r[high].key >= pivotkey) --high;
        L.r[low] = L.r[high];           // 比枢轴小的移到左边
        while (low < high && L.r[low].key <= pivotkey) ++low;
        L.r[high] = L.r[low];           // 比枢轴大的移到右边
    }
    L.r[low] = L.r[0];                 // 枢轴归位
    return low;
}
```

- 初始有序时退化为 O(n²)（枢轴每次只排除一个元素）
- 优化：三数取中法选枢轴，避免最坏情况

### 堆排序（高频手工题）

**大顶堆**：`arr[i] >= arr[2i+1]` 且 `arr[i] >= arr[2i+2]`（完全二叉树层序编号）

**建堆**：从最后一个非叶子结点 `⌊n/2⌋` 开始，向前逐个「筛选下沉」（AdjustDown）

**排序**：反复执行「堆顶与末尾交换 → 堆大小减 1 → 重新调整堆」直到有序

```python
# 堆排序 Python 实现
def heap_sort(arr):
    n = len(arr)
    # 建大顶堆：从最后一个非叶子结点开始筛选
    for i in range(n // 2 - 1, -1, -1):
        adjust_down(arr, i, n)
    # 排序：堆顶（最大）交换到末尾，逐步缩小堆
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        adjust_down(arr, 0, i)

def adjust_down(arr, i, n):
    """将 arr[i] 向下调整，使 arr[i:n] 满足大顶堆"""
    largest = i
    left, right = 2*i+1, 2*i+2
    if left < n and arr[left] > arr[largest]:  largest = left
    if right < n and arr[right] > arr[largest]: largest = right
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        adjust_down(arr, largest, n)

arr = [4, 6, 8, 5, 9]
heap_sort(arr)
print(arr)  # [4, 5, 6, 8, 9]
```

### 归并排序

- 分治：将序列不断二分，直到单个元素，再两两合并为有序序列
- **趟数** = ⌈log₂n⌉，每趟比较 n 次，总计 O(n·log n)
- 空间 O(n)（需辅助数组存放合并结果）

### 基数排序（非比较排序）

- 按关键字的各位分配 + 收集，从最低位到最高位（LSD）或反之（MSD）
- 例：对三位整数，先按个位分配到 10 个桶收集，再按十位、百位重复
- 时间 O(d·(n+r))，d=位数，r=基数（桶数）

## 易错点 / 高频考点

- [ ] 快排最坏 O(n²)（初始有序或逆序时），平均 O(n·log n) 时**是最快的**内排序
- [ ] 堆排序建堆从 `⌊n/2⌋` 开始（最后一个非叶子结点），不是从 n 开始
- [ ] 稳定排序：直接插入、冒泡、归并、基数排序；**不稳定**：希尔、快排、选择、堆
- [ ] 归并排序空间 O(n)，是唯一在最坏情况下仍保证 O(n·log n) 且稳定的排序
- [ ] 基数排序不是基于比较的排序，时间复杂度不受 O(n·log n) 下界约束
- [ ] 外部排序：多路平衡归并，需 ⌈log_k(m)⌉ 趟（k=路数，m=初始归并段数）

## 经典例题

### 例题：堆排序手工建堆

**题干**：对序列 {4, 6, 8, 5, 9} 建大顶堆，写出建堆过程。
**解答**：
1. n=5，从 ⌊5/2⌋-1=1 开始（结点 6，下标 1）
2. 结点 6 的孩子是 5(左) 和 9(右)，9 最大，交换 6 和 9 → {4,**9**,8,**6**,5}
3. 结点 4（下标 0），孩子 9(左) 和 8(右)，9 最大，交换 4 和 9 → {**9**,4,**8**,6,5}
4. 4 下沉后孩子是 6(左) 和 5(右)，6 最大，交换 4 和 6 → {9,**6**,8,**4**,5}
5. 建堆完成：{9, 6, 8, 4, 5}

### 例题：快排一趟划分

**题干**：{49, 38, 65, 97, 76, 13, 27, 49'}，以 49 为枢轴，写出一趟划分结果。
**解答**：枢轴 49；从右找 < 49 的 27 放到左边；从左找 > 49 的 65 放到右边；... 最终枢轴 49 归位，左侧全 < 49，右侧全 ≥ 49。
