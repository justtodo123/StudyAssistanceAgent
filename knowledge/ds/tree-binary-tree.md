## 一句话概括

二叉树是每个结点至多有两棵子树的树形结构。三种遍历（前/中/后序）是基础，线索二叉树利用空链域加前驱/后继指针加速遍历；哈夫曼树是 WPL 最小的带权二叉树，常考手工构造与编码。本章是选择题和算法题的高频出题区。

## 核心概念

### 二叉树基本性质（必背）

| 性质 | 内容 |
| --- | --- |
| 性质 1 | 第 i 层至多有 2^(i-1) 个结点 |
| 性质 2 | 深度 k 的二叉树至多有 2^k - 1 个结点（满二叉树） |
| **性质 3** | **n₀ = n₂ + 1**（叶子数 = 度 2 结点数 + 1）—— 最常考 |
| 性质 4 | n 个结点完全二叉树深度 = ⌊log₂n⌋ + 1 |
| 性质 5 | 完全二叉树层序编号：结点 i 的左孩子 2i，右孩子 2i+1，双亲 ⌊i/2⌋ |

> **性质 3 推导**：n = n₀+n₁+n₂，分支数 = n-1 = n₁+2n₂，两式相减得 n₀ = n₂+1。

### 二叉树存储

- **顺序存储**：用数组按层序编号，适合完全二叉树；斜树浪费空间
- **链式存储（二叉链表）**：`{lchild, data, rchild}`，n 个结点有 n+1 个空指针域（2n - (n-1) = n+1）

### 遍历二叉树

三种递归定义 + 层次遍历：

| 遍历 | 顺序 | 典型应用 |
| --- | --- | --- |
| 前序 DLR | 根→左→右 | 复制二叉树、前缀表达式 |
| 中序 LDR | 左→根→右 | BST 有序输出 |
| 后序 LRD | 左→右→根 | 释放二叉树、后缀表达式 |
| 层次 | 逐层从左到右（队列实现） | 求树深度、逐层打印 |

**已知前序+中序 → 唯一确定二叉树**（高频考点）：
- 前序第一个 = 根；在中序中找根的位置，左边是左子树，右边是右子树
- 递归处理左右子树

```c
// 由前序+中序构造二叉树（简化示意）
BiTree BuildTree(int preL, int inL, int len) {
    if (len == 0) return NULL;
    BiTree T = (BiTree)malloc(sizeof(BiTNode));
    T->data = pre[preL];                   // 前序第一个是根
    int rootIdx = FindIn(inL, len, T->data); // 在中序中定位根
    int leftLen = rootIdx - inL;
    T->lchild = BuildTree(preL+1, inL, leftLen);
    T->rchild = BuildTree(preL+1+leftLen, rootIdx+1, len-leftLen-1);
    return T;
}
```

### 线索二叉树

- n 个结点的二叉链表有 n+1 个空链域，线索化后用它们存放前驱 / 后继指针
- 结点结构：`{LTag, lchild, data, rchild, RTag}`
  - `LTag=0`：lchild 指左孩子；`LTag=1`：lchild 指前驱
  - `RTag=0`：rchild 指右孩子；`RTag=1`：rchild 指后继
- 线索化规则：对某种遍历序列，左孩子为空指向前驱，右孩子为空指向后继

### 树与森林的转换（高频选择题）

- **树 → 二叉树**（孩子兄弟表示法）：每个结点保留第一个孩子作为左孩子，兄弟作为右孩子
- **森林 → 二叉树**：各棵树分别转换后，后一棵树的根作为前一棵树根的右孩子
- **遍历对应**：树的先根 = 对应二叉树前序；树的后根 = 对应二叉树中序；森林先序 = 二叉树前序

## 关键原理 / 算法

### 哈夫曼树构造（高频手工题）

**步骤**：
1. n 个权值各建一棵单结点树，构成森林 F
2. 选 F 中权值最小的两棵树合并（左小右大），新根权值 = 两子树权值之和
3. 删除原两棵树，新树加入 F
4. 重复直到 F 只剩一棵树

**关键结论**：
- 哈夫曼树**没有度为 1 的结点**
- n 个叶子的哈夫曼树有 **2n - 1** 个结点
- **WPL（带权路径长度）** = Σ(叶子权值 × 路径长度)

### 哈夫曼编码

- 左分支标 0，右分支标 1，从根到叶子的路径即该字符的编码
- 是**最优前缀码**（没有一个编码是另一个的前缀），保证解码唯一

```python
# WPL 计算示例（2017 春真题 Q3 变式）
# w = {A:0.29, B:0.07, C:0.09, D:0.16, E:0.25, F:0.01, G:0.02, H:0.11}
# 手工构造后得到各字符编码长度，WPL = Σ(wi × li)
# 例：若 A 编码长 2, B 编码长 5, ... 则 WPL = 0.29×2 + 0.07×5 + ...
```

## 易错点 / 高频考点

- [ ] n₀ = n₂ + 1 是**严格等式**，与树的形状无关（只要二叉树成立）
- [ ] 前序+中序可唯一确定二叉树；后序+中序也可以；**前序+后序不行**（不唯一）
- [ ] 线索二叉树的「线索」是利用空指针域，不额外分配内存
- [ ] 哈夫曼编码左 0 右 1 是约定，考试以题目要求为准；关键在于路径长度计算
- [ ] 树→二叉树转换后根结点没有右孩子；森林→二叉树后各棵树根通过右孩子串联
- [ ] 完全二叉树层序编号性质 5 是堆排序的理论基础

## 经典例题

### 例题 1：已知遍历序列还原二叉树

**题干**：前序 ABDECFG，中序 DBEACFG，画出二叉树。
**解答**：
1. 前序首元素 A 为根；中序中 A 左侧 DBE 为左子树，右侧 CFG 为右子树
2. 左子树前序 BDE、中序 DBE → B 为根，左子树 D，右子树 E
3. 右子树前序 CFG、中序 CFG → C 为根，左子树 F（叶），右子树 G（叶）

### 例题 2：哈夫曼编码

**题干**：字符频率 A:29, B:7, C:9, D:16, E:25, F:1, G:2, H:11，构造哈夫曼树并求 WPL。
**解答**：按权值从小到大不断合并最小两棵树；画出最终二叉树后，WPL = Σ(每个叶子权值 × 其路径长度)。（具体构造过程见 2017 春真题 Q3）
