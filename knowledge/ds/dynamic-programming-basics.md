## 一句话概括（TL;DR）

> 动态规划把具有重叠子问题和最优子结构的问题拆成状态，通过保存子问题答案避免重复计算。关键不是“套表”，而是明确状态、转移、边界和计算顺序。

## 核心概念

- **最优子结构**：原问题的最优解可以由子问题的最优解组合得到。
- **重叠子问题**：递归展开中会反复求解相同子问题，适合使用记忆化或递推表缓存。
- **状态定义**：`dp[i]` 或 `dp[i][j]` 必须清楚说明“已经处理了什么、当前最优值表示什么”。

## 关键原理 / 算法

- 自顶向下记忆化保留递归写法，只在首次访问状态时计算；自底向上递推按依赖顺序填表，通常避免递归栈。
- 状态转移应覆盖所有合法决策，并通过 `max`、`min`、求和或布尔运算组合子状态。
- 若当前状态只依赖前一层，可用滚动数组压缩空间；压缩前要确认更新方向不会覆盖仍需使用的旧状态。

## 易错点 / 高频考点

- [ ] 贪心可行不等于动态规划可省略；要证明局部选择是否产生全局最优。
- [ ] 初始化是状态转移的一部分，`dp[0]`、不可达状态和负无穷值必须按题意设置。
- [ ] 统计方案数与求最优值的转移不同，不能只把 `max` 换成加法而忽略重复计数。

## 经典例题

**题干**：求长度为 `n` 的斐波那契数列第 n 项，并分析递归和动态规划复杂度。

**解答**：朴素递归会重复计算，时间复杂度为指数级；令 `dp[0]=0`、`dp[1]=1`，再使用 `dp[i]=dp[i-1]+dp[i-2]` 自底向上计算，时间为 O(n)，滚动变量可把空间降为 O(1)。
