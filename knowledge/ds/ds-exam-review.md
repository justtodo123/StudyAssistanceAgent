## 一句话概括

2017 春 A 卷覆盖全书核心内容：时间复杂度分析（7 个函数识别）、KMP next 数组、哈夫曼编码、递归函数求值、链表逆序打印、哈希与数字根、首字符去重、DEAP 结构、矩阵公共元素。题型为选择 + 编程解答，编程题每题 4 分共 20 分。

## 一、选择题复盘

### Q1：时间复杂度识别（Stanford 风格，7 个函数）

给出 7 个 C 函数，从 A~F 中选择时间复杂度（A=log₂N, B=N, C=N·log N, D=N², E=2ᴺ, F=N!）：

| 函数 | 描述 | 复杂度 |
| --- | --- | --- |
| i | 单层循环 `for i=0..N x++` | B: O(N) |
| ii | 双层循环 `for i; for j<i` | D: O(N²) |
| iii | 递归+循环 `x+=f(N-1)` | F: O(N!)（枚举全排列） |
| iv | 递归 `f(N/2)+f(N)+f(N/2)` | C: O(N·log N)（类似归并） |
| v | 循环 `for i=N; i>0; i/=2 x+=f(i)` | B: O(N)（N+N/2+N/4+...） |
| vi | 递归 `f(N-1)+f(N-1)` | E: O(2ᴺ)（枚举子集） |
| vii | 递归 `1+f(N/2)` | A: O(log N)（类似二分） |

> **关键思路**：识别递归式结构——f(N-1)+f(N-1) = 2f(N-1) → 2ᴺ；f(N/2) → log N。

### Q2：KMP next 数组

**题干**：模式串 "abbcde"，求 next 数组。

| j | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| T[j] | a | b | b | c | d | e |
| next[j] | 0 | 1 | 2 | 1 | 1 | 1 |

> j=3 时 "ab" 最长相等前后缀 "a" 长 1，next=2；j=4 时 "abb" 无相等前后缀，next=1。

### Q3：哈夫曼树构造

**题干**：权值 {21, 25, 5, 17, 9, 23, 30}，选择正确的构造序列。

**答案**：D（5, 9, 17, 21, 23, 25, 30）—— 按升序排列后依次合并最小两棵。

> 哈夫曼构造的核心：每次选权值最小的两棵树合并，所以初始序列排序后从小到大处理。

### Q4：哈希函数设计

**题干**：设计哈希函数，使 H(k) = H(k-1) + k*(k-1)/2。

> 这是一种增量哈希设计思路，利用前一个哈希值递推当前值，减少重复计算。

### Q5：递归函数求值

**题干**：`f(x) = x>0 ? x*f(x-1) : 2`，求 `f(f(1))`。

**解答**：
- f(0) = 2（base case）
- f(1) = 1 × f(0) = 2
- f(f(1)) = f(2) = 2 × f(1) = 4
- **答案：B（4）**

> 陷阱：f(0)=2 而不是 1，所以 f(1)=2 而不是 1！注意 base case 的值。

### Q6：哈希冲突

**题干**：h₀=2，处理冲突相关计算。

> 哈希冲突处理：线性探测 di=1,2,3,...；二次探测 di=±1², ±2²,...；链地址法。

## 二、编程/解答题复盘（每题 4 分）

### Q1：链表逆序打印（递归）

```c
void PrintListReversely(ListNode* pListHead) {
    if (pListHead != NULL) {
        if (pListHead->m_pNext != NULL) {
            PrintListReversely(pListHead->m_pNext);  // 先递归到最后
        }
        printf("%d ", pListHead->m_nKey);             // 回溯时打印
    }
}
```

**测试**：{5,7,6,9,11,10,8} → 输出 8 10 11 9 6 7 5

**分析**：递归深度 = 链表长度 n，空间 O(n)；本质是利用递归栈实现逆序。

### Q2：数字根函数 + 布尔数组

```c
int find(int k) {
    int m = k, o = k;
    for (int p = 1; p <= 3; p++) {
        o = o + m % 10;   // 加上最低位
        m = m / 10;        // 去掉最低位
    }
    return o;
}
// 示例：find(78) → 78+8+7+0 = 93
```

**主程序逻辑**：bool[1000] 数组，对 1~1000 每个 n，计算 m=find(n)，标记 bool[m]=true。

**分析**：find(k) 将 k 的各位数字之和加到 k 上。对于三位数以内，最多加 3 次个位。

### Q3：查找第一个不重复字符

```c
char firstUnique(char *arr) {
    char asc[255] = {0};
    for (int i = 0; arr[i] != '\0'; i++)
        asc[arr[i]]++;              // 统计频次
    for (int i = 0; arr[i] != '\0'; i++)
        if (asc[arr[i]] == 1)       // 找第一个频次为 1 的
            return arr[i];
    return '\0';
}
```

**测试**："abaccdeffb" → 统计 a=2, b=2, c=2, d=1, e=1, f=2 → 返回 'd'

**分析**：两次遍历字符串，第一次统计频次 O(n)，第二次找第一个频次为 1 的 O(n)，总计 O(n)。空间 O(1)（255 大小固定数组）。

### Q4：DEAP 结构（双端堆）

DEAP = Double-Ended AP：
- 完全二叉树，左半部分为**最小堆**（min-heap），右半部分为**最大堆**（max-heap）
- 分界规则：若 n 个结点，左子树有 m=2^(h-1) 个结点（h 为树高）
- 关键性质：左半任意结点 ≤ 右半任意结点

**DEAP 插入 {15, 20, 19, 25}**：
- 15 插入左半（min-heap），20 插入右半（max-heap）
- 19 插入左半，25 插入右半
- 需检查左右半之间的大小关系，必要时交换

> DEAP 支持同时高效查找最小值和最大值（O(1)），插入 O(log n)。

### Q5：矩阵公共元素（Stanford）

**题干**：N×N 矩阵，每行已排序，找所有行中都出现的最大公共元素。

**算法**：
1. 对每行堆排序 → O(N²·log N)
2. 对第 0 行从大到小每个元素，在其余 N-1 行中二分查找
3. 返回第一个在所有行都出现的元素

**时间复杂度**：O(N²·log N)（瓶颈在排序和二分查找）

**正确性**：最大公共元素必在第 0 行中，从大到小扫描确保找到最大的。
