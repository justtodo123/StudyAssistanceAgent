## 一句话概括

指令系统（ISA）是软硬件的分界面，定义了 CPU 能执行的所有操作。指令格式决定编码效率，寻址方式决定操作数的获取方式，CISC 与 RISC 是两种设计哲学。本章概念题为主。

## 核心概念

### 指令格式

```
指令 = 操作码 + 地址码
```

| 指令格式 | 地址码个数 | 示例 |
| --- | --- | --- |
| 三地址 | 3 | `OP A1, A2, A3`：A1 OP A2 → A3 |
| 二地址 | 2 | `OP A1, A2`：A1 OP A2 → A1 |
| 一地址 | 1 | `OP A1`：ACC OP A1 → ACC |
| 零地址 | 0 | `OP`：如 NOP、RET |

**操作码扩展**：固定长度操作码简单但浪费；可变长度（扩展操作码）用短码表示常用指令，长码表示非常用指令，提高编码效率。

### 寻址方式（高频考点）

| 寻址方式 | 有效地址 | 特点 |
| --- | --- | --- |
| **立即寻址** | 操作数在指令中 | 速度快，操作数小 |
| **直接寻址** | EA = A（地址码即有效地址） | 简单，寻址范围小 |
| **间接寻址** | EA = (A)（地址码指向的内存单元存 EA） | 灵活，访存次数多 |
| **寄存器寻址** | 操作数在寄存器中 | 最快，数量有限 |
| **寄存器间接** | EA = (R)（寄存器存地址） | 兼顾速度和灵活 |
| **基址寻址** | EA = (BR) + A | 适合程序浮动（BR 由 OS 设） |
| **变址寻址** | EA = (IX) + A | 适合数组访问（IX 由用户改） |
| **相对寻址** | EA = (PC) + A | 适合跳转指令（PC 相对偏移） |

> **基址 vs 变址**：基址寻址中基址寄存器由**操作系统**设定（程序重定位），变址寻址中变址寄存器由**程序员**修改（循环遍历数组）。

### CISC vs RISC

| 特征 | CISC | RISC |
| --- | --- | --- |
| 指令数量 | 多（数百条） | 少（几十条） |
| 指令长度 | 可变 | 固定 |
| 寻址方式 | 多种 | 少（Load/Store 架构） |
| 访存方式 | 任意指令可访存 | 只有 Load/Store 访存 |
| CPI | 高（>1） | 低（理想 1） |
| 代表 | x86（Intel/AMD） | ARM、MIPS、RISC-V |

> RISC 的核心思想：简化指令 → 简化硬件 → 提高时钟频率 → 用编译器优化弥补指令简单。

## 易错点 / 高频考点

- [ ] 基址寻址和变址寻址的**区别**：谁设定/修改寄存器值
- [ ] 相对寻址中偏移量是**有符号数**，可向前或向后跳转
- [ ] 间接寻址需要**两次访存**（第一次取 EA，第二次取操作数）
- [ ] RISC 的 Load/Store 架构：只有这两条指令能访问内存
