## 一句话概括

存储系统利用**局部性原理**构建层次结构（寄存器 → Cache → 主存 → 磁盘），核心目标是让 CPU 看到「大容量 + 高速度 + 低价格」。Cache 地址映射、替换算法、命中率计算是期考大题高频出题区。

## 核心概念

### 存储层次结构

```
寄存器 ←→ Cache ←→ 主存 ←→ 磁盘 ←→ 光盘/磁带
 速度快、容量小、价格高 ←——————————→ 速度慢、容量大、价格低
```

**局部性原理**：
- **时间局部性**：刚访问的地址短期内可能再次被访问（循环）
- **空间局部性**：访问某地址后，附近地址可能被访问（数组遍历）

### Cache 基本原理

Cache 是主存的**副本**，CPU 访存时先查 Cache：
- **命中**（Hit）：数据在 Cache 中，直接读取
- **缺失**（Miss）：数据不在 Cache，从主存取出并放入 Cache

**命中率** h = 命中次数 / 总访问次数
**平均访问时间** = h × t_cache + (1-h) × t_miss（t_miss 包含替换开销）

### 地址映射方式（高频考点）

| 映射方式 | 原理 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **直接映射** | 主存块固定映射到 Cache 某行：`Cache行号 = 主存块号 mod Cache行数` | 简单、速度快 | 冲突率高 |
| **全相联** | 主存块可放入 Cache 任意行 | 冲突率最低 | 硬件复杂、比较慢 |
| **组相联** | Cache 分组，主存块映射到固定组，组内全相联 | 折中方案 | 适度复杂 |

**地址分解**（直接映射）：

```
主存地址 = [标记 Tag | Cache行号 | 块内偏移]
```

- Tag：标记该 Cache 行存放的是主存的哪一块
- Cache 行号：直接映射的目标行
- 块内偏移：块内具体字节

**组相联地址分解**：

```
主存地址 = [标记 Tag | 组号 | 块内偏移]
```

### 替换算法

当 Cache 满且需装入新块时，选择哪块被替换：

| 算法 | 策略 | 特点 |
| --- | --- | --- |
| FIFO | 最先进入的块先替换 | 简单，但可能替换常用块 |
| **LRU** | 最近最少使用的块先替换 | 效果好，硬件实现用计数器 |
| LFU | 使用频率最低的块先替换 | 需要计数器，开销大 |
| 随机 | 随机选择 | 简单，效果不稳定 |

### Cache 写策略

| 策略 | 命中时 | 未命中时 |
| --- | --- | --- |
| 写直达（Write Through） | 同时写 Cache 和主存 | 写分配 / 不写分配 |
| **写回（Write Back）** | 只写 Cache，设脏位 | 写分配（调入后写） |

> 写回法减少主存写入次数，但需要**脏位**标记修改过的块。

### 虚拟存储器

- **虚拟地址**（逻辑地址）→ **物理地址**的映射
- **页式虚拟存储**：虚拟地址 = 虚页号 + 页内偏移
- **页表**：虚页号 → 物理页号的映射表
- **TLB（快表）**：页表的 Cache，加速地址转换
- **缺页中断**：访问的页不在主存时触发，需从磁盘调入

**多级 Cache 访存时间计算**：

```
平均时间 = h₁×t₁ + (1-h₁)×h₂×t₂ + (1-h₁)×(1-h₂)×t₃
```

## 易错点 / 高频考点

- [ ] 直接映射的 Cache 行号 = 主存块号 **mod** Cache 行数，不是整除
- [ ] LRU 和 FIFO 在某些访问模式下效果不同（Belady 异例只出现在 FIFO）
- [ ] 写回法需要脏位，写直达不需要
- [ ] TLB 是**页表的 Cache**，不是主存的 Cache
- [ ] 虚拟存储器的命中率与 Cache 命中率计算方式相同，但粒度是页级

## 经典例题

**题干**：Cache 容量 16KB，块大小 64B，直接映射，主存地址 32 位。求 Tag、行号、偏移各占几位。
**解答**：
- 块内偏移：log₂64 = 6 位
- Cache 行数：16KB / 64B = 256 行，行号 log₂256 = 8 位
- Tag：32 - 8 - 6 = 18 位
