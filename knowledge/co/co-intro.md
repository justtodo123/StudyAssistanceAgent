## 一句话概括

计算机组成原理研究计算机硬件系统各功能部件的组成与工作原理。冯诺依曼体系以「存储程序」为核心，五大部件（运算器、控制器、存储器、输入、输出）协同工作。本章建立全书框架与性能评价基础。

## 核心概念

### 冯诺依曼体系结构

- **核心思想**：程序和数据以二进制形式存储在存储器中，计算机按程序顺序自动执行指令
- **五大部件**：运算器（ALU）、控制器（CU）、存储器、输入设备、输出设备
- **特点**：以运算器为中心（现代计算机改为以存储器为中心）
- **局限**：指令和数据共用总线，形成瓶颈（哈佛结构将指令和数据分开存储）

### 计算机层次结构

| 层次 | 说明 |
| --- | --- |
| 高级语言层 | C/Java/Python 等 |
| 汇编语言层 | 助记符指令 |
| 操作系统层 | 系统调用、资源管理 |
| 指令集架构层（ISA） | 软硬件分界面，程序员可见 |
| 微体系结构层 | 数据通路、控制器实现 |
| 逻辑门层 | 与或非门、触发器 |
| 器件层 | 晶体管、硅片 |

> ISA 是**软硬件的分界面**：向上提供编程模型，向下定义硬件实现规范。

### 性能评价

**CPU 执行时间**（核心公式）：

```
CPU 时间 = 指令数 × CPI × 时钟周期
         = 指令数 × CPI / 时钟频率
```

- **CPI**（Cycles Per Instruction）：每条指令平均时钟周期数
- **MIPS**（百万条指令/秒）：MIPS = 指令数 / (执行时间 × 10⁶)
- **MFLOPS**（百万浮点操作/秒）：衡量浮点性能

> Amdahl 定律：系统加速比 S = 1 / ((1-f) + f/s)，f 为可加速比例，s 为局部加速比。瓶颈在不可加速部分。

## 易错点 / 高频考点

- [ ] 冯诺依曼以**运算器**为中心，现代计算机以**存储器**为中心
- [ ] ISA 是软硬件分界面，不是操作系统层
- [ ] CPI 是**平均值**，不同指令类型 CPI 不同
- [ ] Amdahl 定律中 f 是**可加速部分的比例**，不是总时间
