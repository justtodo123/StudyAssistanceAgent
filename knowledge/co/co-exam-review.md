## 一句话概括

本条目汇总组成原理期末/考研高频考点、典型计算题型和易错点，用于考前快速复习。

## 高频考点分类

### 选择题高频（概念辨析）

| 考点 | 关键区分 |
| --- | --- |
| 补码 vs 原码 vs 反码 | 补码多表示一个 -2ⁿ⁻¹ |
| 基址 vs 变址寻址 | OS 设 vs 用户改 |
| CISC vs RISC | 指令数/长度/寻址方式/访存限制 |
| 中断 vs DMA | CPU 参与程度 |
| Cache 写直达 vs 写回 | 是否需要脏位 |
| 硬布线 vs 微程序控制器 | 速度 vs 灵活性 |
| 单周期 vs 多周期 vs 流水线 | 时钟周期的确定方式 |

### 计算题高频

| 题型 | 关键公式/步骤 |
| --- | --- |
| 补码加减法 | 直接相加，溢出用双符号位判断 |
| IEEE 754 编码/解码 | S+E(移码)+M(隐含1) |
| Cache 地址分解 | Tag + 行号/组号 + 偏移 |
| Cache 命中率/平均时间 | h×t_hit + (1-h)×t_miss |
| 流水线吞吐率/加速比 | TP = n/(k+n-1)×Δt, S = kn/(k+n-1) |
| 海明码校验位数 | 2^r ≥ n+r+1 |
| CPI 计算 | CPU时间 = IC × CPI × T_clk |

### 大题常见出题模式

1. **Cache 设计题**：给容量、块大小、映射方式，求地址分解、命中率、平均访存时间
2. **流水线冒险分析**：给指令序列，识别冒险类型，画流水线时空图
3. **CPU 数据通路**：给定指令，描述其在数据通路中的执行过程
4. **I/O 方式对比**：程序查询/中断/DMA 三种方式的效率计算

## 易错点速查

- [ ] 补码最小负数没有对应正数（-128 的补码 10000000，+128 无法用 8 位表示）
- [ ] IEEE 754 偏置值 127（单精度），阶码 E=0 和 E=255 是特殊值
- [ ] Cache 组相联：组内全相联，组间直接映射
- [ ] 流水线 Load-Use 必须停顿 1 拍，数据前递无法解决
- [ ] DMA 周期挪用方式下，CPU 可能在某些周期访存被延迟
- [ ] 中断向量表存放入口地址，不是中断服务程序本身
