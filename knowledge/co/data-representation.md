## 一句话概括

数据表示解决「如何用二进制编码数值和字符」。补码统一了加减法运算，IEEE 754 标准化了浮点数格式，校验码用于检测/纠正传输错误。本章是选择题和计算题的高频出题区。

## 核心概念

### 进制与编码

| 编码 | 范围（n 位） | 特点 |
| --- | --- | --- |
| 无符号整数 | 0 ~ 2ⁿ-1 | 全部位用于数值 |
| 原码 | -(2ⁿ⁻¹-1) ~ +(2ⁿ⁻¹-1) | +0 和 -0 不同 |
| 反码 | 同原码 | 负数按位取反 |
| **补码** | **-2ⁿ⁻¹ ~ +(2ⁿ⁻¹-1)** | **+0=-0，多表示一个数** |
| 移码 | 同补码范围 | 补码符号位取反，用于浮点数阶码 |

### 补码运算（高频考点）

**补码加法**：`[A+B]补 = [A]补 + [B]补`（直接相加，符号位参与运算）

**补码减法**：`[A-B]补 = [A]补 + [-B]补`（减法转加法）

**溢出检测**：
- **一位符号位**：两个正数相加得负（正溢出），两个负数相加得正（负溢出）
- **双符号位（变形补码）**：`00` 正、`01` 正溢出、`10` 负溢出、`11` 负

```python
# 8 位补码示例
# +5 = 00000101, -3 = 11111101
# +5 + (-3) = 00000101 + 11111101 = 00000010 = +2 ✓
# +100 + +50 = 01100100 + 00110010 = 10010110 → 负数！正溢出！
```

### 定点数与浮点数

**定点数**：小数点位置固定。定点整数（小数点在最低位之后）或定点小数（小数点在符号位之后）。

**浮点数表示**：`N = M × 2^E`（M 为尾数，E 为阶码）

**IEEE 754 单精度（32 位）**：

| 符号 S | 阶码 E（8 位） | 尾数 M（23 位） |
| --- | --- | --- |
| 1 位 | 移码表示（偏置 127） | 隐含前导 1 |

- **真值**：`(-1)^S × 1.M × 2^(E-127)`
- **特殊值**：
  - E=0, M=0：±0
  - E=255, M=0：±∞
  - E=255, M≠0：NaN
  - E=0, M≠0：非规格化数 `(-1)^S × 0.M × 2^(-126)`

```
示例：求 -12.75 的 IEEE 754 单精度表示
1. |-12.75| = 1100.11(B) = 1.10011 × 2³
2. S=1（负数），E=3+127=130=10000010(B)，M=1001100...
3. 结果：1 10000010 10011000000000000000000
```

### 校验码

| 校验码 | 原理 | 检错/纠错能力 |
| --- | --- | --- |
| 奇偶校验 | 附加 1 位使 1 的个数为奇/偶 | 检测奇数位错，不能纠错 |
| 海明码 | k 个校验位覆盖不同位组 | 可检 2 位错、纠 1 位错 |
| CRC | 模 2 除法求余数 | 可检测突发错误 |

**海明码校验位数**：`2^r ≥ n + r + 1`（n 为数据位数，r 为校验位数）

## 易错点 / 高频考点

- [ ] 补码比原码多表示一个最小负数（如 8 位补码可表示 -128）
- [ ] IEEE 754 隐含前导 1，尾数实际精度 24 位（含隐含位）
- [ ] 阶码用**移码**（不是补码），偏置值 127（单精度）/ 1023（双精度）
- [ ] 溢出判断只在**同号数相加**时才可能发生
- [ ] 海明码校验位放在 2 的幂次位置（1, 2, 4, 8, ...）

## 经典例题

**题干**：用 8 位补码计算 (-6) + (-3) 的结果，并判断是否溢出。
**解答**：
- [-6]补 = 11111010，[-3]补 = 11111101
- 相加：11111010 + 11111101 = 11110111
- 结果为负数补码，转原码：-(0001001) = -9 ✓，无溢出（两个负数相加仍为负）
