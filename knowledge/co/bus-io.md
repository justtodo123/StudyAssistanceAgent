## 一句话概括

总线是 CPU、存储器、I/O 设备之间的公共数据通道；I/O 系统解决 CPU 如何与慢速外部设备高效通信。程序查询、中断、DMA 三种 I/O 方式的对比是高频考点。

## 核心概念

### 总线

**分类**：
- **数据总线**：传输数据，宽度 = 字长
- **地址总线**：传输地址，宽度决定寻址范围
- **控制总线**：传输控制信号（读/写、中断请求等）

**总线仲裁**（多设备争用总线时谁先用）：

| 仲裁方式 | 原理 | 特点 |
| --- | --- | --- |
| 链式查询 | 设备串行连接，离控制器近的优先 | 简单，不灵活 |
| 计数器定时查询 | 计数器从某设备开始轮询 | 较公平 |
| **独立请求** | 每个设备有独立请求/允许线 | 速度快，线多 |

### I/O 方式（高频对比考点）

| 方式 | 原理 | CPU 参与 | 适用场景 |
| --- | --- | --- | --- |
| **程序查询** | CPU 轮询设备状态寄存器 | 全程参与 | 简单、慢速设备 |
| **程序中断** | 设备准备好后发中断请求 | 启动+中断处理 | 中速设备（键盘、打印机） |
| **DMA** | DMA 控制器直接访问主存 | 仅启动和结束 | 高速设备（磁盘、网卡） |
| **通道** | 专用处理器执行通道程序 | 仅启动 | 大型机 I/O |

### 中断系统

**中断响应过程**：
1. 设备发中断请求（IRQ）
2. CPU 在**当前指令执行完**后检测中断
3. 关中断 → 保存断点（PC + PSW）→ 识别中断源 → 转中断服务程序
4. 执行中断服务程序
5. 恢复断点 → 开中断 → 返回断点继续执行

**中断优先级**：硬件故障 > 程序异常 > 外部中断 > I/O 中断

**中断屏蔽**：通过中断屏蔽字控制哪些中断可被响应。

### DMA（直接内存访问）

- DMA 控制器接管总线，直接在 I/O 设备和主存之间传输数据
- CPU 只在传输**开始**（设定地址、字数、方向）和**结束**（DMA 发中断通知）时参与
- 传输过程中 CPU 可以执行其他指令（不占用 CPU）

**DMA 传送方式**：
- 停止 CPU 访存：CPU 让出总线，DMA 独占（CPU 空闲）
- **周期挪用**：DMA 在 CPU 不访存的时钟周期插入（常用）
- DMA 与 CPU 交替访存：时间片轮转

## 易错点 / 高频考点

- [ ] 程序查询 CPU **全程参与**，效率最低；DMA 只参与首尾，效率最高
- [ ] 中断响应在**指令执行完**后，不是在指令执行中
- [ ] DMA 传输时 CPU **不能**访问主存（停止 CPU 访存方式）或需等空闲周期（周期挪用）
- [ ] 中断向量表存放的是**中断服务程序的入口地址**
