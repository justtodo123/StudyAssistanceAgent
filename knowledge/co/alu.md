## 一句话概括

运算器（ALU）是 CPU 的计算核心，执行算术和逻辑运算。加法器从串行进位到先行进位逐步优化速度，乘法和除法通过移位+加减实现。溢出检测是数据表示与运算器的衔接考点。

## 核心概念

### 加法器

**全加器**：输入 A、B、进位 Cin，输出 Sum 和进位 Cout。
- `Sum = A ⊕ B ⊕ Cin`
- `Cout = AB + (A⊕B)·Cin`

**串行进位加法器（行波进位）**：低位的 Cout 连到高位的 Cin，逐位传递。
- 简单但慢：n 位加法器延迟 O(n)

**先行进位加法器（CLA）**：同时计算所有位的进位，延迟 O(log n)
- 生成信号 Gᵢ = AᵢBᵢ，传播信号 Pᵢ = Aᵢ⊕Bᵢ
- Cᵢ₊₁ = Gᵢ + Pᵢ·Cᵢ，展开后可并行计算

### 补码乘法

**Booth 算法**（补码一位乘法）：
- 从最低位开始，相邻两位差决定操作：
  - `0→1`（+1）：加被乘数
  - `1→0`（-1）：减被乘数
  - `0→0` 或 `1→1`：不操作
- 每步右移一位，共 n 步

**阵列乘法器**：硬件并行计算所有部分积后相加，速度快但面积大。

### 除法

**恢复余数法**：余数减除数，若为负则恢复（加回除数），商 0；否则商 1。

**不恢复余数法（加减交替法）**：
- 余数减除数后若为负，不恢复，下一步**加**除数，商 0
- 余数为正，下一步**减**除数，商 1
- 比恢复余数法少一次加法

### 溢出检测

| 方法 | 条件 |
| --- | --- |
| 一位符号位 | 同号数相加，结果符号与操作数不同 → 溢出 |
| 双符号位 | 两位不同 → 溢出（01 正溢，10 负溢） |
| 进位位 | 最高位进位 ≠ 次高位进位 → 溢出 |

### 浮点数运算

1. **对阶**：小阶向大阶看齐，尾数右移
2. **尾数加减**：对阶后直接运算
3. **规格化**：结果规范化为 1.M × 2^E 形式
4. **舍入**：右移丢失的位按规则舍入（0 舍 1 入 / 恒置 1）
5. **溢出判断**：阶码超出表示范围

## 易错点 / 高频考点

- [ ] Booth 算法处理的是**补码**乘数，直接用补码运算，无需转原码
- [ ] 不恢复余数法的「不恢复」指的是余数为负时不加回除数，下一步直接加
- [ ] 浮点数对阶是**小阶向大阶**看齐（尾数右移），不是大阶向小阶
- [ ] 双符号位溢出判断：01=正溢，10=负溢，00/11=正常
