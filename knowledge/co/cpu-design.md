## 一句话概括

CPU 由数据通路（执行部件）和控制器（指挥部件）组成。流水线通过重叠执行提高吞吐率，但会遇到数据冒险、控制冒险和结构冒险。本章是组成原理的核心大题出题区。

## 核心概念

### 数据通路

CPU 执行指令的基本路径：

```
取指：PC → 指令存储器 → IR
译码：IR → 控制器 → 生成控制信号
执行：寄存器/立即数 → ALU → 结果
访存：地址 → 数据存储器 → 数据
写回：结果 → 寄存器堆
```

**关键部件**：寄存器堆、ALU、指令/数据存储器、多路选择器（MUX）、控制单元

### 控制器

| 类型 | 原理 | 特点 |
| --- | --- | --- |
| **硬布线控制器** | 组合逻辑电路直接产生控制信号 | 速度快，设计复杂，不易修改 |
| **微程序控制器** | 微指令存储在控制存储器中 | 灵活，可修改，速度较慢 |

**微程序**：一条机器指令对应一段微程序，微程序由若干微指令组成。

### 流水线（核心考点）

将指令执行分为多个阶段，各阶段并行工作：

```
时钟周期:  1    2    3    4    5    6    7
指令1:    取指  译码  执行  访存  写回
指令2:          取指  译码  执行  访存  写回
指令3:                取指  译码  执行  访存  写回
```

**性能指标**：
- **吞吐率** TP = n / (k+n-1)×Δt（n=指令数，k=级数，Δt=时钟周期）
- **加速比** S = k×n / (k+n-1)（理想 k 倍，实际略低）
- **效率** E = S / k（各段利用率）

### 流水线冒险（高频考点）

**结构冒险（资源冲突）**：多条指令争用同一硬件
- 解决：资源复制（如指令 Cache 和数据 Cache 分开）

**数据冒险（数据冲突）**：后面的指令依赖前面指令的结果

| 冒险类型 | 示例 | 解决方法 |
| --- | --- | --- |
| RAW（写后读） | `ADD R1,R2,R3; SUB R4,R1,R5` | **数据前递/旁路**（forwarding） |
| WAR（读后写） | 不会在顺序流水线中出现 | 乱序执行时需处理 |
| WAW（写后写） | 同上 | 乱序执行时需处理 |

**前递（Forwarding/Bypassing）**：将 ALU 结果直接送到下一条指令的 ALU 输入，不等写回。

**Load-Use 冒险**：`LW R1, 0(R2); ADD R3, R1, R4` — 数据在访存后才可用，必须**停顿 1 周期**。

**控制冒险（转移冲突）**：分支指令改变 PC，后续指令已取指可能错误
- 解决：**分支预测**（静态/动态）、延迟分支、尽早计算分支目标

## 易错点 / 高频考点

- [ ] 流水线吞吐率公式中分子是 n（指令数），不是 n-1
- [ ] 数据前递**不能**解决 Load-Use 冒险（必须停顿 1 拍）
- [ ] 流水线级数越多，理论加速比越大，但冒险和切换开销也越大
- [ ] 硬布线控制器适合 RISC（指令规整），微程序控制器适合 CISC（指令复杂）

## 经典例题

**题干**：5 级流水线（取指、译码、执行、访存、写回），执行 100 条指令，求吞吐率和加速比。
**解答**：
- 总时间 = (5 + 100 - 1) × Δt = 104Δt
- TP = 100 / 104Δt ≈ 0.96/Δt
- S = (100 × 5) / 104 ≈ 4.81
