## 一句话概括

浮点数运算遵循 IEEE 754 标准。加减法五步：对阶→尾数加减→规格化→舍入→溢出判断；乘法三步：阶码相加→尾数相乘→规格化舍入。对阶时小阶向大阶看齐（右移尾数），舍入误差是精度损失的根源。本章是计算题高频考点，需掌握手工模拟。

## 核心概念

### 浮点数格式回顾（IEEE 754 单精度）

```
| 符号 S(1) | 阶码 E(8) | 尾数 M(23) |
真值 = (-1)^S × 1.M × 2^(E-127)
```

- 隐含前导 1（规格化数），实际尾数精度 24 位
- 偏置值 127（单精度），阶码用移码表示

### 浮点数加减法（高频考点）

**五步流程**（以 A + B 为例）：

```
步骤 1：对阶
  - 求阶差 ΔE = E_A - E_B
  - 小阶向大阶看齐：小的尾数右移 |ΔE| 位，阶码对齐
  - 右移会丢失精度（保护位保留移出的位）

步骤 2：尾数加减
  - 对阶后直接对尾数做定点加减法
  - 若减法，转为加 [-B]补

步骤 3：规格化
  - 结果可能需要左规（前导 0 多）或右规（溢出）
  - 左规：尾数左移 1 位，阶码减 1（可能多次）
  - 右规：尾数右移 1 位，阶码加 1（溢出时 1 次）

步骤 4：舍入
  - 尾数右移或精度超出时需舍入
  - 常见方式：
    - 就近舍入（四舍五入，IEEE 默认）
    - 朝 +∞ / 朝 -∞ / 朝 0（截断）

步骤 5：溢出判断
  - 阶码上溢（E > 254）→ 结果溢出（±∞ 或异常）
  - 阶码下溢（E < 1）→ 结果为 0 或非规格化数
```

**手工计算示例**：

```
A = 1.101 × 2² (E=2), B = 1.011 × 2⁴ (E=4)
1. 对阶：A 的阶码小，尾数右移 2 位 → A = 0.01101 × 2⁴
2. 尾数加：0.01101 + 1.011 = 1.11001 × 2⁴
3. 已规格化（前导 0 后是 1）
4. 无需舍入
5. 阶码 4 在正常范围，无溢出
结果：1.11001 × 2⁴
```

### 浮点数乘法

**三步流程**：

```
步骤 1：阶码相加
  - E_结果 = E_A + E_B - 偏置值（减一次偏置，因为两个偏置码相加会多一次）

步骤 2：尾数相乘
  - 两个 24 位尾数相乘，得到 48 位积
  - 取高 24 位作为结果尾数

步骤 3：规格化 + 舍入 + 溢出判断
  - 同加减法的步骤 3-5
```

**符号**：S_结果 = S_A ⊕ S_B（异或）

### 浮点数除法

```
步骤 1：阶码相减 → E_结果 = E_A - E_B + 偏置值
步骤 2：尾数相除 → M_A / M_B
步骤 3：规格化 + 舍入 + 溢出判断
```

### 特殊值运算规则

| 运算 | 结果 |
| --- | --- |
| 有限数 / 有限数 | 正常计算 |
| ±∞ + ±∞ | 同号得 ±∞，异号得 NaN |
| 有限数 × ±∞ | ±∞（符号相乘） |
| 0 / 0 | NaN |
| 有限数 / 0 | ±∞ |
| NaN 参与任何运算 | NaN |

### 舍入误差与精度

- **保护位（Guard Bit）**、**舍入位（Round Bit）**、**粘滞位（Sticky Bit）**：对阶右移时保留额外 3 位，提高舍入精度
- 浮点加法**不满足结合律**：`(a+b)+c ≠ a+(b+c)` 可能成立
- 浮点乘法**不满足分配律**
- 机器精度 ε：1.0 与大于 1 的最小可表示数之差（单精度约 1.19×10⁻⁷）

## 易错点 / 高频考点

- [ ] 对阶是**小阶向大阶**看齐（尾数右移），不是反过来
- [ ] 浮点乘法的阶码要**减一次偏置值**（两个移码相加多了一次偏置）
- [ ] 左规可能多次，右规最多 1 次
- [ ] 溢出判断看**阶码**，不是看尾数
- [ ] 浮点运算不满足结合律和分配律——这是选择题常考陷阱
- [ ] 规格化数的尾数隐含前导 1，非规格化数（E=0）隐含前导 0

## 经典例题

### 例题：浮点数加法

**题干**：用 IEEE 754 单精度计算 `0.5 + (-0.4375)`，写出步骤。

**解答**：
```
0.5   = 1.0000000 × 2⁻¹ → S=0, E=126, M=000...0
-0.4375 = -1.1100000 × 2⁻² → S=1, E=125, M=110...0

1. 对阶：-0.4375 阶码小，右移 1 位 → -0.01110000 × 2⁻¹
2. 尾数加：1.0000000 + (-0.0111000) = 0.1001000 × 2⁻¹
3. 左规 1 次：1.0010000 × 2⁻²，E = 125
4. 无需舍入
5. E=125 在正常范围

结果：S=0, E=125, M=0010000...0 → 十进制 = 0.0625 ✓
```
