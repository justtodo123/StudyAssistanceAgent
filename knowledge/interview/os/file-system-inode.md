## 面试问题

文件系统 inode 与目录：目录通常保存文件名到 inode 的映射，inode 保存权限、所有者、大小、时间和数据块位置。文件名不是文件内容本身，硬链接共享 inode。

## 回答要点

设计文件系统时要区分元数据、目录项和数据块。删除文件名不一定立即删除数据，只有链接计数归零且没有打开引用时才可回收。

## 项目结合点

知识库索引使用相对路径作为稳定出处，不能把显示标题当成唯一身份；条目 ID 和文件路径需要保持可追踪。
