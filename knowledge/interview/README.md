## 阅读与检索方式

- 先按课程目录浏览，再按条目的 `tags` 聚合主题。
- 通过 API 检索时，使用“面试”“追问”“原理”等关键词；结果会携带 `knowledge/interview/...` 来源。
- QA 会把面经条目和课程笔记一起作为上下文；回答时应优先引用具体文件，不把未检索到的内容当成事实。

## 条目结构

每条记录必须包含以下 frontmatter：

```yaml
---
title: 条目标题
course: interview
tags: [topic1, topic2]
difficulty: 入门 | 中等 | 进阶
updated: 2026-08-18
---
```

正文建议包含四个二级标题：

1. `## 面试问题`：用一两句话给出定义或结论。
2. `## 回答要点`：补充边界、权衡、易错点。
3. `## 项目结合点`：联系 StudyAssistanceAgent 的真实实现。
4. `## 继续追问`：准备下一层为什么、怎么做和如何验证。

## 维护规范

- 只写提炼后的可复用内容，不复制 `D:I_Others_Subjects` 中的 PDF、PPT、实验工程或其他二进制资料。
- 外部资料只通过 `docs/reference/` 索引指向；新增条目时同步更新目录导航。
- 更新正文时刷新 `updated` 字段，并保留已有条目的问题边界和项目结合点。
