## 一句话概括（TL;DR）

> DNS 把域名翻译为 IP，采用树形域名空间+分布式层次服务器。本地 DNS 可递归或迭代查询，通过缓存加速。

## 核心概念

### 域名结构

- 树形：主机名.三级域.二级域.顶级域
- 顶级域：国家(.cn)、通用(.com)、基础结构(.arpa)

### 四类服务器

- 根域名服务器（13 个逻辑根）
- 顶级域服务器
- 权威域名服务器
- 本地域名服务器

### 查询方式

- **递归查询**：代查到底并返回
- **迭代查询**：指路自己问

### 记录类型

| 类型 | 含义 |
|---|---|
| A | IPv4 地址 |
| CNAME | 别名 |
| MX | 邮件交换（带优先级） |
| NS | 权威 DNS |
| PTR | 反向解析 |

## 易错点 / 高频考点

- [ ] 主机只对本地 DNS 用递归
- [ ] 13 个根是逻辑根，实际大量镜像
- [ ] MX 带优先级用于收邮件

## 经典例题

**题干**：Web 解析用什么记录？邮件用什么记录？
**解答**：Web 用 A 记录，邮件用 MX 记录。
