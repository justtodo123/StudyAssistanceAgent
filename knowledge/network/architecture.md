## 一句话概括（TL;DR）

> OSI 七层模型是理论标准，TCP/IP 四层模型是事实标准，408 主要考察五层模型。各层 PDU 不同，封装由上而下加首部、解封装自下而上剥首部。

## 核心概念

### 协议与分层

- **协议**（水平）：三要素为语法、语义、时序。
- **服务**（垂直）：下层为上层提供功能。

### OSI 七层模型（"物数网传会表应"）

| 层次 | PDU | 主要功能 |
|---|---|---|
| 物理层 | 比特 | 透明传输比特流 |
| 数据链路层 | 帧 | 成帧、差错检测、MAC 寻址 |
| 网络层 | 分组 | IP 寻址、路由选择、分组转发 |
| 传输层 | 报文段 | 端到端连接管理、可靠传输 |
| 会话层 | 报文 | 建立/管理/终止会话 |
| 表示层 | 报文 | 数据格式转换、加密、压缩 |
| 应用层 | 报文 | HTTP/FTP/DNS 等接口 |

### TCP/IP 四层 / 五层模型

- 五层 = 物理 + 数据链路 + 网络 + 传输 + 应用（合并会话/表示到应用层）。
- TCP/IP 无独立会话层与表示层。

### 封装与解封装

- 发送方：message → segment → packet → frame → bit
- 接收方：逐层剥首部还原。

## 易错点 / 高频考点

- [ ] PDU：比特→帧→分组→报文段→报文
- [ ] 传输层数据单位是"报文段"（TCP）/"用户数据报"（UDP）
- [ ] 网络层不负责可靠传输，可靠传输由传输层负责
- [ ] TCP/IP 无独立会话层、表示层

## 经典例题

**题干**：数据在发送方由应用层传递到物理层，数据单位依次是什么？
**解答**：报文→报文段→分组→帧→比特流。
