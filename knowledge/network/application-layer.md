## 一句话概括（TL;DR）

> 应用层协议按模型分 C/S（服务器常监听）与 P2P（每个节点既是客户又是服务器）。协议三要素：语法/语义/同步。

## 核心概念

### C/S vs P2P

| 维度 | C/S | P2P |
|---|---|---|
| 服务器 | 专用、常监听 | 无专用服务器 |
| 扩展性 | 差（瓶颈） | 好 |
| 典型 | HTTP/FTP/DNS | BT/IP电话 |

### 常见端口

| 协议 | 端口 | 传输层 |
|---|---|---|
| HTTP | 80 | TCP |
| HTTPS | 443 | TCP |
| FTP | 20/21 | TCP |
| SMTP | 25 | TCP |
| DNS | 53 | UDP |

## 易错点 / 高频考点

- [ ] DNS=53(UDP)，DHCP=67/68(UDP)
- [ ] FTP 用两个端口 20/21
- [ ] SMTP 只管发，POP3/IMAP 只管收

## 经典例题

**题干**：下载软件既从其他用户获取分片又提供分片，属于哪种模型？
**解答**：P2P 模型，每个节点同时扮演客户与服务器。
