## 一句话概括（TL;DR）

> IPv4 首部固定 20 字节，地址分 A/B/C/D/E 类。超长数据报按 MTU 分片，片偏移以 8 字节为单位。

## 核心概念

### IP 数据报首部（固定 20B）

- 标识：同一报文分片共用
- DF=1 禁止分片，MF=1 后面还有分片
- 片偏移：相对首片，单位 8B
- TTL：每跳−1，为 0 丢弃

### 分类地址

| 类 | 开头 | 网络/主机位 |
|---|---|---|
| A | 0 | 8/24 |
| B | 10 | 16/16 |
| C | 110 | 24/8 |
| D | 1110 | 组播 |

### 特殊地址

- 0.0.0.0：本主机
- 127.0.0.1：环回
- 10/8, 172.16/12, 192.168/16：私有地址

## 易错点 / 高频考点

- [ ] 片偏移单位 8B，计算时必须除 8
- [ ] 首部校验和只算首部不算数据
- [ ] 分类编址主机数要 −2

## 经典例题

**题干**：总长 4020B（首部 20B），MTU=1500，求各片。
**解答**：每片最多 1480B 数据 → 片1 偏移 0/MF=1、片2 偏移 185/MF=1、片3 偏移 370/MF=0。
