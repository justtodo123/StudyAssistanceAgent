## 一句话概括（TL;DR）

> 核心指标是四种时延（发送/传播/处理/排队）、带宽、吞吐量与信道利用率。高频公式：带宽-时延积 = 传播时延 × 带宽，信道利用率 = 发送时间 /（发送时间 + RTT）。

## 核心概念

### 四种时延

- **发送时延** = 数据长度 / 发送速率
- **传播时延** = 信道长度 / 传播速率（与带宽无关）
- **处理时延**：路由器检错、选路时间
- **排队时延**：分组在队列中等待时间

### 带宽与吞吐量

- **带宽**：信道最高数据率
- **吞吐量**：实际通过的数据量，受瓶颈链路限制
- **时延带宽积** = 传播时延 × 带宽（链路上同时存在的最大比特数）

### 信道利用率

- 利用率 = 发送时间 /（发送时间 + 2×传播时延）
- 利用率趋近 1 时排队时延急剧增大

## 易错点 / 高频考点

- [ ] 发送时延看数据量与带宽；传播时延看距离与介质
- [ ] 光纤传播速率约 2×10⁸ m/s，不是真空光速
- [ ] 吞吐量 ≤ 带宽，受最慢链路约束
- [ ] 时延带宽积单位是 bit

## 经典例题

**题干**：带宽 1Mbps，单程传播时延 10ms，帧长 1000bit，求停等利用率。
**解答**：Tt = 1000/1M = 1ms；U = 1/(1+2×10) = 1/21 ≈ 4.76%。
