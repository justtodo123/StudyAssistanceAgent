## 一句话概括（TL;DR）

> 安全服务：机密性（加密）、完整性（MAC/签名）、认证（签名+证书）、不可抵赖（签名）。被动攻击难检测能预防，主动攻击能检测难预防。

## 核心概念

### 威胁分类

- **被动攻击**：窃听，难检测，靠加密预防
- **主动攻击**：篡改/伪造/重放/DoS，能检测

### 安全服务→机制映射

- 窃听 → 机密性 → 加密
- 篡改 → 完整性 → MAC/签名
- 伪造 → 认证 → 签名+证书
- 重放 → 时间戳/序号/nonce

## 易错点 / 高频考点

- [ ] 重放防御是时间戳/nonce，不是加密
- [ ] 数字签名同时提供认证+完整性+不可抵赖
- [ ] 被动攻击难检测能预防，主动攻击反之

## 经典例题

**题干**：黑客截获报文后原样重发，属于什么攻击？如何防御？
**解答**：重放攻击。用序号/时间戳/nonce 防御。
