## 一句话概括（TL;DR）

> TCP 靠序号+确认+重传保证可靠。序号给字节流编号，累积确认告知已正确收到的位置，超时或重复 ACK 时重传。发送窗口 = min(rwnd, cwnd)。

## 核心概念

### 序号与确认

- 序号 = 报文段首字节在字节流中的位置
- 确认号 = 期望收到的下一个字节序号
- 累积确认：只确认按序到达的最后一个字节

### 滑动窗口

- 发送窗口 = min(rwnd, cwnd)
- rwnd 由接收方缓存决定，通过窗口字段通告

### 超时重传

- RTO = RTTs + 4×RTTd
- RTTs = (1-1/8)×RTTs + 1/8×RTT样本
- 超时 RTO 翻倍

## 易错点 / 高频考点

- [ ] 序号是字节编号，不是报文段编号
- [ ] 确认号是"期望的下一个序号"
- [ ] 发送窗口由 rwnd 与 cwnd 共同决定

## 经典例题

**题干**：连续发 101、301、501（各 200 字节），按序收到前两段，确认号？
**解答**：最后正确字节 500，确认号 = 501。
