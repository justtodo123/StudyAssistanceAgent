## 一句话概括

进程调度决定就绪队列中哪个进程获得 CPU。不同算法在吞吐量、等待时间、公平性上有取舍，考试常考计算平均等待时间与判别适用场景。

## 核心概念

### 调度时机

- 进程从运行态转为：就绪（时间片到，被抢占）、阻塞（等待 I/O）、结束
- 终止/阻塞时进行调度（非抢占），时间片耗尽时（抢占式）

### 常见调度算法

| 算法 | 特点 | 抢占 | 平均等待 | 缺点 |
| --- | --- | --- | --- | --- |
| FCFS 先来先服务 | 按到达顺序 | 否 | 可能很大（护航效应） | 短作业被长作业拖慢 |
| SJF 短作业优先 | 选最短运行时间 | 可抢占（SRTF） | 最小（不可抢占时） | 需预知运行时间，可能饥饿 |
| RR 时间片轮转 | 每个就绪进程一个时间片 | 是 | 依赖时间片大小 | 时间片过小切换开销大 |
| 优先级 | 选优先级最高 | 可 | 低优先级进程可能饥饿 | 用老化解决饥饿 |
| 多级反馈队列 | 多队列、动态优先级 | 是 | 兼顾交互与吞吐 | 实现复杂 |
| 最高响应比优先 HRRN | 响应比=(等待+服务)/服务 | 否 | 折中 SJF 与 FCFS | 需计算动态响应比 |

## 关键原理 / 算法

平均等待时间计算（非抢占 SJF 示例）：

- 作业 A(0,8) B(1,4) C(2,9) D(3,5)，括号为(到达,运行)
- 调度顺序：A(8)→B(4)→D(5)→C(9)
- 等待：A=0, B=8-1=7, C= (8+4+5)-2=15, D=(8+4)-3=9
- 平均等待 = (0+7+15+9)/4 = 7.75

```python
# 用 Python 模拟 FCFS 平均等待时间（示例）
def fcfs_avg_wait(times):
    arrive, burst = zip(*times)
    start = 0
    total_wait = 0
    for i, b in enumerate(burst):
        wait = max(0, start - arrive[i])
        total_wait += wait
        start += b
    return total_wait / len(times)
```

## 易错点 / 高频考点

- [ ] SJF 抢占式（SRTF）与不可抢占式的「平均等待最小」结论只在特定条件成立
- [ ] 时间片大小对 RR 的影响（过大退化为 FCFS，过小切换开销大）
- [ ] 优先级算法需要配合「老化 Aging」防饥饿
- [ ] 处理器调度 vs I/O 调度区别

## 经典例题

**题干**：三个进程 A(0,3) B(1,5) C(3,2)，用非抢占 SJF，求平均等待时间。
**解答**：调度顺序 A→C→B；A 等待 0，C 等待 (3+3)-3=3，B 等待 (3+3+2)-1=7；平均 = (0+3+7)/3 ≈ 3.33。
