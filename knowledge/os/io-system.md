## 一句话概括

I/O 系统管理计算机中最慢、最复杂的部分——外围设备，通过分层软件屏蔽硬件差异，用中断/DMA 减少 CPU 等待，用缓冲/SPOOLing 提高吞吐。

## 核心概念

### I/O 控制方式（演进主线）

| 方式 | CPU 角色 | 数据传输 | 适用 |
| --- | --- | --- | --- |
| 程序直接控制 (Polling) | CPU 全程轮询状态寄存器，忙等 | CPU 从设备寄存器取字→存内存 | 极简单设备 |
| 中断驱动 | CPU 发 I/O 命令后继续其它任务；I/O 完成发中断 | 每次中断只传一字 | 低速设备 |
| DMA (直接存储器访问) | 仅参与起止：初始化→DMA 控制器接管总线→完成中断 | 块传输，不经过 CPU 寄存器 | 高速块设备（磁盘） |
| 通道 (Channel) | 专门的 I/O 处理器，执行通道程序 | 比 DMA 更灵活，自主控制 | 大型机 |

**DMA 工作流程**（高频）：
1. CPU 设置 DMA 控制器：源地址、目标地址、传输字节数、方向
2. DMA 控制器**窃取总线周期**（cycle stealing），逐字传输
3. 传输完成，DMA 发中断通知 CPU

### I/O 软件层次（自下而上）

```
中断处理程序 ── 设备具体
   ↓
设备驱动程序 ── 设备相关，不同设备不同驱动
   ↓
设备无关 OS 软件 ── 命名、保护、缓冲、分配、错误处理
   ↓
用户层 I/O 软件 ── 库函数（printf/scanf）、SPOOLing 系统
```

- **设备驱动程序**：与设备控制器交互的唯一途径；每类设备一个驱动
- **设备无关层**功能：设备命名映射、访问保护、缓冲管理、独占设备分配、错误处理

### 缓冲技术（目的：缓解 CPU-设备 速度差）

| 方式 | 说明 | 特点 |
| --- | --- | --- |
| 单缓冲 | 1 个缓冲区 | 处理时间 = max(C, T) + M（C=计算, T=I/O, M=搬移） |
| 双缓冲 | 2 个交替使用 | 处理时间 = max(C, T)，流水线并行 |
| 循环缓冲 | 多个，环形队列 | 适合生产者-消费者模式下的持续 I/O |
| 缓冲池 | 统一管理共享缓冲区 | 三个队列：空/输入/输出，四种工作模式 |

> 考试常考：给定 C、T、M，计算不同缓冲方案的吞吐量。

### SPOOLing（假脱机）

- 将**独占设备**（如打印机）改造为**可共享的虚拟设备**
- 组成：输入/输出井（磁盘）+ 输入/输出进程
- **打印机 SPOOLing**：用户进程将打印数据写入磁盘缓存 → SPOOLing 守护进程逐个输出
- 核心作用：独占→共享、低速→高速、缓和速度矛盾

### 设备独立性

- 用户用**逻辑设备名**（如 `/dev/printer`），不必指定物理设备
- LUT（逻辑设备表）：逻辑名 → 物理设备映射
- 好处：设备重定向灵活（输出到文件 or 打印机都可）

## 易错点 / 高频考点

- [ ] DMA 传输的是「数据块」，不是单个字——与中断驱动的核心区别
- [ ] SPOOLing 不是缓冲，是**虚拟设备**技术（独占设备→共享）
- [ ] 双缓冲理论上可将处理时间降到 max(C, T)，但前提是缓冲区交换开销可忽略
- [ ] 「设备驱动程序运行在内核态」√，「属于设备无关层」❌

## 经典例题

**题干**：某系统 CPU 处理一块数据耗时 C=2ms，I/O 传输耗时 T=4ms，内存复制耗时 M=0.2ms。计算无缓冲、单缓冲、双缓冲下处理 100 块的总耗时。
**解答**：无缓冲（串行）=(C+M+T)×100=620ms；单缓冲=hook: max(C,T)+M=4.2ms，100×4.2=420ms；双缓冲=max(C,T)=4ms，100×4=400ms（近似，首块多 C 即 402ms）。
