# 项目计划 · StudyAssistanceAgent

> 面向大学计算机专业学生的个人学习助手。初版聚焦「知识库 + Agent 工作流」，逐步演进到更智能的学习辅助能力。
> 状态图例：⬜ 未开始 ｜ 🔄 进行中 ｜ ✅ 完成

## 一、项目目标与愿景

**目标**：让每个计算机课程知识点都能被快速找到、理解、复习。Agent 根据个人资料库与知识库，提供构建式学习辅助（提问答疑、计划生成、复习排程、面经整理）。

**范围（MVP 边界）**：
- 【是】知识库（Markdown 笔记）为核心资产，随仓库版本化
- 【是】Agent 工作流：基于 Claude Code 的 agents + skills 完成资料梳理、答疑、计划生成
- 【是】外部资料索引 + 精炼笔记并存
- 【否】Web 界面 / 独立后端（后续可演进，见路线图）

**成功指标（MVP）**：
1. 5 门核心课程具备可用笔记（OS、DS、CO、DB、Algo）
2. 任一课程向 Agent 提问，能从知识库 + 外部索引返回准确、带出处的解答
3. 具备可复用的复习排程 / 计划生成流程（skill 或脚本）

## 二、里程碑

### M0：仓库与规范初始化（当前）
- ✅ 仓库基础文件（.gitignore、README、LICENSE）
- ✅ CLAUDE.md 项目指导与开发规范
- ✅ Git 提交规范（Conventional Commits + Commitizen）
- ✅ 知识库框架（知识库目录 + 条目模板）
- ✅ 参考资料索引（docs/reference/ 与外部目录映射）
- ✅ 项目计划（本文档）
- ⬜ 接入 GitHub 远程仓库
- **退出条件**：初始框架提交完成，远程仓库可克隆。

### M1：知识库第一期（核心专业课，优先 OS）
> 目标：让「知识问答 + 复习」真正可用。
- ⬜ 操作系统：建 `knowledge/os/`，整理进程/线程、调度、同步互斥、死锁、内存管理、文件系统 → 产出 ~20 篇条目，1 篇真题复盘
- ⬜ 数据结构复习：`knowledge/ds/`，按五大板块（线性表/树/图/查找/排序）建 NAV 页 + 高频真题题库
- ⬜ 计算机组成原理：`knowledge/co/`，数据表示/运算器/存储/Cache/CPU/总线 + MIPS CPU 实验复盘
- ⬜ 建立「知识问答」 agents/skills（答疑：注出处 + 具名引用知识库文件）
- **退出条件**：OS 条目 ≥20 篇、其余 2 门 ≥10 篇；提问测试通过 3 类典型问题（概念/例题/复习建议）。

### M2：学习辅助能力
- ⬜ 学习计划生成：输入课程+目标（考试/面经），输出到 `docs/plans/` 的学习计划（skill）
- ⬜ 复习排程：基于遗忘曲线（间隔重复）的复习提醒流程
- ⬜ 面经整理：按知识点聚合面经题 → 建 `knowledge/interview/`
- ⬜ 资料整理引导：半自动扫描外部目录（脚本）+ 人工拣选 → 知识库入库流程
- **退出条件**：3 种能力均有可用 skill/脚本且经本人试用。

### M3：系统性沉淀与演进选型
- ⬜ 补齐核心课后续章节与题库
- ⬜ 评估知识库检索增强（向量化/全文检索）与是否需要前端形态（Web / CLI / 笔记迁移）
- ⬜ 沉淀个人知识方法论（笔记规范被实际使用后的复盘与裁剪）
- **退出条件**：M1 三门课全部完成 ≥20 篇、面经库 ≥50 题、演进方向选定。

## 三、技术栈与约束

- **知识库**：纯 Markdown + frontmatter（无数据库依赖，零依赖、易迁移）
- **Agent 层**：Claude Code 体系（agents + skills + CLAUDE.md）
- **脚本**：Node.js / Python（辅助生成索引、校验 frontmatter）
- **外部资料**：`D:\111_Others_Subjects`（只读引用，禁止复制大文件入仓库）
- **约束**：个人项目，接受适度手工整理；仓库体积控制在 KB 量级（只含 md/json/代码）。

## 四、风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 外部资料海量（40 万+ 文件）难以整理 | 只整理知识增量而非全量；优先真题/高频考点；用索引而非复制 |
| 笔记日渐陈旧 | 条目 `updated` 字段；复习排程触发复核；每次会话收尾检查 |
| Agent 答疑引用到过时/错误内容 | 条目标注 `source`；答案要求带出处；面经/真题单独维护校验 |
| 个人精力不足，计划落空 | M1 从自己最急的课程（如 OS 考前）切入；里程碑可裁剪 |

## 五、后续演进（out-of-scope 收集箱）

- Web 界面（笔记浏览 + 答疑对话框）

- 面经自动抓取与去重
