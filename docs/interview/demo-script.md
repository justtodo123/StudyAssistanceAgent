# Demo 脚本 — StudyAssistanceAgent 面试演示

> 时长约 2 分钟，按顺序演示 5 个核心功能。每个环节标注了**演示操作**和**讲解要点**。

---

## 准备

1. 启动服务：`python tools/start_local.py`
2. 打开浏览器访问 `http://127.0.0.1:8000/`
3. 确认健康检查：`/health` 返回 `index_size: 682`（4 门课程：os/ds/co/network）

---

## 1. 智能问答（30 秒）

**操作**：
- 切到「智能问答」标签
- 输入问题：`什么是死锁？产生的四个必要条件是什么？`
- 课程选「操作系统」，勾选「流式输出」
- 点击提问

**讲解要点**：
- 后端用 BM25 关键词检索从 682 个知识块中召回 Top-K 相关片段（覆盖 4 门课程）
- 检索结果附带出处（file + course），实现**可溯源的 RAG**
- 流式输出走 SSE 协议（`/api/v1/qa/stream`），前端用 ReadableStream 逐 token 渲染
- 未配置 LLM 时自动降级为笔记摘要（`note_summary`），不会报错——这是**优雅降级**设计
- 配置 LLM 后切换为 `grounded_llm` 层，基于检索上下文生成回答

---

## 2. 检索展示（15 秒）

**操作**：
- 切到「智能问答」上方第一个标签（即搜索页，如果有的话）或直接展示问答返回的出处列表

> 注：当前前端将搜索集成在问答结果中。如需单独演示检索，可用 API 直接调用：
> ```bash
> curl -X POST http://127.0.0.1:8000/api/v1/search \
>   -H "Content-Type: application/json" \
>   -d '{"question":"进程调度算法","top_k":5,"course":"os"}'
> ```

**讲解要点**：
- 多路召回架构：BM25（关键词）+ 可选向量检索（BGE-small-zh）
- 支持按课程过滤、Top-K 可调
- 每条结果带 BM25 评分和来源文件路径

---

## 3. 测验生成（20 秒）

**操作**：
- 切到「测验练习」标签
- 课程选「操作系统」，题目数 5，难度选「medium」
- 主题填「进程调度,死锁」
- 点击生成

**讲解要点**：
- 系统从知识库中按主题和难度筛选候选条目
- 自动生成三种题型：**经典例题**（example）、**检索题**（retrieval）、**概念题**（concept）
- 顶部统计显示题库总量、筛后数量、各题型分布
- 例题附带可折叠的参考答案

---

## 4. 复习计划（20 秒）

**操作**：
- 切到「复习计划」标签
- 课程选「操作系统」，目标日期默认 14 天后，每天 2 小时
- 点击生成

**讲解要点**：
- 基于**艾宾浩斯遗忘曲线**的间隔重复算法（1→2→4→8→16→32 天）
- 根据条目难度和优先级自动分配每日任务
- 输出按天分组的复习计划，含预估时长和难度标签
- 与学习会话联动：完成学习后自动记录复习日期

---

## 5. 学习会话（30 秒）

**操作**：
- 切到「学习会话」标签
- 课程选「操作系统」，主题填「死锁」
- 点击「开始学习」
- 阅读系统生成的知识讲解
- 在作答区回答问题，提交
- 查看反馈和掌握度评分

**讲解要点**：
- 完整的**学习闭环**：检索 → 讲解 → 出题 → 作答 → 评估 → 复习调度
- 会话状态机：`awaiting_answer` → `completed`
- 评估结果包含正确性判断和针对性反馈
- 完成后自动计算下次复习日期（间隔重复）
- 底部「工具调用轨迹」展示每一步的 service 和 status，便于调试

---

## 6. 今日待复习（15 秒）

**操作**：
- 切到「今日待复习」标签
- 展示待复习列表（如果有）
- 点击某条待复习项，自动跳转到学习会话并填入主题

**讲解要点**：
- 查询今日到期的复习条目，支持按课程过滤
- 点击即可进入学习流程——**复习调度与学习会话无缝衔接**
- 逾期条目会显示逾期天数

---

## 收尾话术

> 整个系统基于 FastAPI 构建，后端实现了多路召回 RAG、带处处的问答、流式 SSE、
> 间隔重复复习调度、学习会话状态机等核心能力。前端是纯 Vanilla JS 的 SPA，
> 零依赖，直接由 FastAPI 静态文件服务托管。
>
> 架构上支持可选的向量检索引擎（SQLite/Qdrant）和可选的 LLM 层（OpenAI 兼容协议），
> 未配置时自动降级，保证开箱可用。
>
> 项目包含完整的测试体系（阶段隔离 + 回归套件）和 CI 流水线。

## 常见面试追问准备

| 问题 | 回答要点 |
|------|---------|
| 为什么不用 LangChain？ | 核心检索和调度逻辑不依赖框架，用原生 Python 实现更可控、更易测试。LangGraph 集成是可选的 M12 增强 |
| RAG 效果怎么评估？ | `tools/run_evaluation.py`，3 课 90 题评测集，衡量召回率和答案质量 |
| 向量检索怎么接入？ | 环境变量 `SA_VECTOR_STORE` 切换 sqlite/linear/qdrant，适配器模式，不改业务代码 |
| 如何保证不产生幻觉？ | 检索结果带出处，LLM 层基于检索上下文生成；无 LLM 时降级为笔记摘要，不编造 |
| 部署方式？ | 单进程 uvicorn，`python tools/start_local.py` 一键启动，适合个人学习场景 |
